# Aktualisierungen

Movue hält sich selbst aktuell. Du musst neue Versionen nicht suchen oder von Hand herunterladen.

## So läuft ein Update

1. Kurz nach dem Start und danach alle sechs Stunden fragt Movue nach, ob es eine neue Version gibt.
2. Gibt es eine, lädt Movue sie im Hintergrund herunter. Unten in der Seitenleiste siehst du den Fortschritt.
3. Ist der Download fertig, erscheint oben ein Hinweis **„Movue … ist da“**.
   - **Jetzt neu starten** installiert die neue Version sofort und startet Movue neu.
   - **Später** blendet den Hinweis aus. Die neue Version wird dann beim nächsten Beenden von Movue installiert.
4. Nach dem Neustart zeigt Movue einmal die Seite **Was ist neu**.

## Unterschiede je nach Installation

- **AppImage**: Das Update läuft vollständig automatisch.
- **.deb-Paket**: Zum Installieren fragt Linux Mint einmal nach deinem Passwort – so wie bei jeder Software, die ins System installiert wird.

## Wenn das automatische Update nicht klappt

Kann Movue die neue Version nicht selbst installieren, zeigt der Hinweis stattdessen **Herunterladen**. Der Knopf öffnet die Seite der neuen Version im Browser. Dort lädst du das .deb-Paket oder das AppImage und installierst es wie beim ersten Mal.

Alle Versionen findest du auch unter [github.com/morogge/movue-linuxmint/releases](https://github.com/morogge/movue-linuxmint/releases).

## Was dabei übertragen wird

Für die Prüfung fragt Movue nur bei GitHub nach der neuesten Version. Dabei werden keine Daten über dich oder deine Nutzung gesendet.
